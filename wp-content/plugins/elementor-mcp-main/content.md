## RESPONSIVE DESIGN NOTES

### Mobile Breakpoints
- **Mobile (320px - 768px):** Single column, stacked layouts, full-width images
- **Tablet (768px - 1024px):** Two-column where possible, larger touch targets
- **Desktop (1024px+):** Multi-column as specified above

### Mobile Image Optimization
- All landscape images should become portrait-oriented on mobile
- Hero section: Image moves below text on mobile
- Section 3 (Vision): Background image simplifies or becomes solid color
- Section 5 (Packages): Horizontal scroll becomes vertical stack
- All cards: Full width, maintain aspect ratios

### Image File Optimization
- Use WebP format for all new images (reduce file size 25-35%)
- Provide JPEG fallback for older browsers
- Compress all images (max 100KB per image)
- Use srcset for responsive images (different sizes for different breakpoints)

### Animation Notes
- **Card Hover:** Slight scale (1.05x) and shadow increase
- **CTA Buttons:** Change color/opacity on hover
- **Testimonial Cards:** Fade in on scroll
- **FAQ Accordion:** Smooth expand/collapse animation
